# Browser Demo
**[Open the published demo](https://light1088.github.io/Interactive-3d-scene/?v=3)**

GitHub Pages publishes the main branch from /(root). The site serves index.html and demo.js directly; visitors do not need to install anything.

## Try it
1. Drag the blue ball and watch the distance change.
2. Click the ball to enlarge it.
3. Select Reset to restore its initial state.
4. In 3D mode, drag empty space to orbit and scroll to zoom.

Browsers without WebGL show a labelled 2D interaction preview. Click, drag, distance updates and Reset have been checked in that preview. Full 3D rendering and headset behaviour still need testing on a compatible device.

## Public adaptation
The supplied coursework implementation was adapted to browser JavaScript with instructions, Reset, floor-plane dragging and asset-loading fallbacks. The original video, school tests and grading scripts are not included. Babylon.js and its loader come from the official CDN; the dragon is a Babylon.js sample asset.
