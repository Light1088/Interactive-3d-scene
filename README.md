# Interactive 3D Scene — Move a Ball and Measure Distance
**Brian Tam · Individual coursework · TypeScript, Babylon.js, WebXR**

A 3D scene where users move a ball, click to enlarge it and see its distance from a dragon model.

## Scene development
The scene begins with **objects, lighting and camera controls**. An **imported dragon** provides a reference. **Click and drag interactions** change the ball, while a **distance label updates every frame**. The coursework also configures **360° video and VR teleportation**.

## Try the browser version
The public adaptation is in [index.html](index.html) and [demo.js](demo.js). It has a reset button and floor-plane dragging. The original video is not included.
